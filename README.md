# GeoFS SAAF Chat Highlighter
Tampermonkey addon that makes SAAF callsigns red and other MRP yellow on the GeoFS Game Chat.
Original addon created by D-1, presumably for USAF, adapted for SAAF by amateurtheairbus.

How to install:
  1. Download the Tampermonkey Chrome extension from the Chrome Web Store. Also works on chromium-based browsers like Helium.
  2. From any tab, click on the puzzle-piece icon by the sarch bar > Tampermonkey > Create a New Script.
  3. Copy userscript.js into the text editor, then use File > Save or Ctrl+S/⌘+S to save.
  4. Reload geo-fs.com, if you have it open. SAAF players on patrol should be highlighted in the chat.
